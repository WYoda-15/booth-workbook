# booth-workbook

Claude 특강용 사이트입니다. GitHub Pages로 배포됩니다.

- `index.html` : 학생 교재 (팀 선택, 이름 입력, 실시간 공유, 퀴즈 점수)
- `ppt.html` : 1주차 강의 화면 (16:9 고정, 교재와 연동, 강사 코드 필요)
- `ppt2.html` : 2주차 강의 화면 (오프닝, 커넥터와 MCP, Claude Code로 실시간 프로그램 만들기, REA와 레퍼런스, 캔바 발표 자료, 퀴즈 10문제)
- `app.html` : 팀이 교재에 올린 프로그램을 여는 화면 (`app.html?t=t1` 처럼 팀 번호를 붙여서 엽니다)
- `ref/` : 수업용 레퍼런스 화면 세 가지 (수업용으로 만든 것이라 자유롭게 참고해도 됩니다)
- `qr.js` : QR 코드를 그리는 라이브러리 (qrcode-generator 1.4.4, MIT, Kazuhiko Arase)
- `steps.js` : 두 화면이 함께 쓰는 실습과 퀴즈 내용
- `media/` : 강의 화면에 쓰는 영상
