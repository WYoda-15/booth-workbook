부록 · 내 주소로 직접 게시하기

수업에서는 교재가 주소를 만들어 주었습니다. 혼자 할 때는 GitHub에 올립니다. 이 교재도 같은 방법으로 열려 있습니다.

  1. github.com 에 무료로 가입하고 로그인합니다
  2. 오른쪽 위 + 에서 New repository 를 누르고, 이름을 쓰고 Public 으로 만듭니다이름은 영어와 숫자로 씁니다. 예: booth-app
  3. Add file 의 Upload files 에 index.html 을 끌어다 놓고 Commit changes 를 누릅니다빈 저장소에서는 "uploading an existing file" 링크를 눌러도 됩니다
  4. Settings 의 Pages 에서 Source를 Deploy from a branch, Branch를 main 으로 고르고 Save 를 누릅니다
  5. 몇 분 뒤 아이디.github.io/저장소 이름 으로 열립니다고칠 때는 3번처럼 파일을 다시 올립니다

부록 · 막혔을 때

Code 탭이 열리지 않습니다

Git을 설치하라는 안내가 나오면 설치하고 Claude를 다시 켭니다. 로그인하라는 안내가 나오면 로그인을 마치고 다시 켭니다.

REA 설치가 끝나지 않습니다

설치에 관리자 권한이 필요하다고 하면 거기서 멈춥니다. 그 팀은 참고할 화면을 캡처해서 Claude에 붙여 넣는 방법으로 이어 갑니다.

교재의 "연결 확인"이 실패합니다

주소 뒤에 다른 글자가 붙지 않았는지 봅니다. Firestore가 아니라 Realtime Database를, 테스트 모드로 만들었는지 봅니다.

링크를 열면 "연결 안 됨"입니다

파일에 우리 팀 주소가 들어 있는지 봅니다. 없으면 Claude에게 주소를 다시 알려 주고 고쳐 달라고 합니다.

파일을 올렸는데 화면이 비어 있습니다

프로젝트 폴더의 index.html 을 골랐는지 봅니다. Claude가 아직 고치는 중이면 끝난 뒤에 다시 올립니다.

Claude가 사용 한도에 걸렸습니다

다른 계정으로 로그인해서 같은 폴더를 다시 엽니다. 파일과 CLAUDE.md 가 폴더에 남아 있어서 이어서 할 수 있습니다.
